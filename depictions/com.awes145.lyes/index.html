lyes
A lightweight equivalent to 'yes'.
lyes is a lightweight equivalent to the 'yes' command.
It indefinitely prints 'y' followed by a newline. This is all it does.
As this is a CLI-tool, you need either MTerminal or MobileTerminal. Or use SSH...
Once this package is installed, run it by typing 'lyes' in the terminal emulator.
lyes and its iOS port were created by awes145.
Compiled with the cctools-port toolchain. apple-libdispatch was also used there.
